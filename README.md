# Week 3 Assignment: Conditions and Loops

This assignment practices Python loops, conditions, running totals, and debugging.

- `grade_reporter.py` - Uses a for loop, running total, and if/elif/else statements to calculate and report grades.
- `bug_hunt.py` - Fixes three bugs in a program that calculates the sum of numbers from 1 to 5.

The hardest bug in Part B to find was the logic bug because the program could run without showing an error message. I knew something was wrong because the program's output did not match the expected result, which should be 15.
